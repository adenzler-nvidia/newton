Default `SolverMuJoCo(use_mujoco_cpu=True)` to one MuJoCo world per Newton world for multi-world models, as on the MuJoCo Warp backend; constructing it without `separate_worlds=True` previously raised. `SolverMuJoCo.get_max_contact_count()` now returns `nconmax` times the world count on both backends; size CPU contact storage from it rather than from `nconmax`. With `use_mujoco_cpu=True`, `solver.mj_data` is now a copy of the first world's data that the solver refreshes after every step, so writing to it no longer changes the simulation; `solver.mj_model` remains the first world's model.
