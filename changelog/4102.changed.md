Default `SolverMuJoCo(use_mujoco_cpu=True)` to one MuJoCo world per Newton world for multi-world models, as on the MuJoCo Warp backend; constructing it without `separate_worlds=True` previously raised. `SolverMuJoCo.get_max_contact_count()` now returns `nconmax` times the world count on both backends; size CPU contact storage from it rather than from `nconmax`. With `use_mujoco_cpu=True`, `solver.mj_model` and `solver.mj_data` are now copies of the first world that the solver refreshes, so writing to them no longer changes the simulation: pass solver options such as `noslip_iterations` to the constructor, and change properties on the Newton model followed by `notify_model_changed()`.
