Default `SolverMuJoCo(use_mujoco_cpu=True)` to one MuJoCo world per Newton world for multi-world models, as on the MuJoCo Warp backend; constructing it without `separate_worlds=True` previously raised. `SolverMuJoCo.get_max_contact_count()` now returns `nconmax` times the world count on both backends; size CPU contact storage from it rather than from `nconmax`. The CPU backend now runs its worlds in a `mujoco.batch.Batch`: `solver.mj_model` and `solver.mj_data` show the first world, and writes to the arrays of `solver.mj_model` no longer affect the simulation, so change the `Model` properties and call `notify_model_changed()` instead; options written to `solver.mj_model.opt` still apply. The batch rejects Python functions installed as MuJoCo physics callbacks (`mujoco.set_mjcb_*`); uninstall them or install C callbacks through `ctypes`.
