Default `SolverMuJoCo(use_mujoco_cpu=True)` to one MuJoCo world per Newton world for multi-world models, as on the MuJoCo Warp backend; constructing it without `separate_worlds=True` previously raised. `SolverMuJoCo.get_max_contact_count()` now returns `nconmax` times the world count on both backends; size CPU contact storage from it rather than from `nconmax`. The CPU backend now steps with `mujoco.batch`, which rejects Python functions installed as MuJoCo physics callbacks (`mujoco.set_mjcb_*`); uninstall them or install C callbacks through `ctypes`.
