Step every world of a multi-world model with `SolverMuJoCo(use_mujoco_cpu=True)`, which previously simulated only the first world. Each world gets its own native MuJoCo model, and a `mujoco.batch.Batch` steps the worlds, so per-world model properties and their runtime updates through `notify_model_changed()` behave as on the MuJoCo Warp backend, and `reset()` clears the native buffers of the selected worlds only. Set the number of stepping threads with the new `nthread` argument. Body observables are now available with every integrator on this backend.
