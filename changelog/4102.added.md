Step every world of a multi-world model with `SolverMuJoCo(use_mujoco_cpu=True)`, which previously simulated only the first world. Each world gets its own native MuJoCo model and data, so per-world model properties and their runtime updates through `notify_model_changed()` behave as on the MuJoCo Warp backend, and `reset()` clears the native buffers of the selected worlds only. The worlds are stepped on a thread pool; set its size with the new `nthread` argument.
